# Meu Port-Fólio
- Este repositório contém meu portfólio pessoal, desenvolvido para apresentar meus projetos, minhas habilidades e minha evolução na área de desenvolvimento de software.

Meu foco principal é o desenvolvimento backend com Python e Django, criando APIs, sistemas web e soluções voltadas para problemas reais. Também trabalho com HTML, CSS e JavaScript para desenvolver interfaces e integrar o frontend aos meus projetos.

# Objetivo
- Compartilhar meus projetos, demonstrar minhas habilidades técnicas e documentar minha evolução como desenvolvedor, buscando constantemente aprender novas tecnologias e aprimorar minhas práticas de programação
